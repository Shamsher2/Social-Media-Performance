
## 📌 Project Overview

An interactive **Social Media Performance Dashboard** built in Microsoft Excel to analyze social media performance across platforms, topics, regions, languages, and content types.

## 📈 Key KPIs

* **Total Posts:** 10,000
* **Total Views:** 2.12B
* **Total Likes:** 152.37M
* **Total Comments:** 58.60M
* **Total Shares:** 23.44M

## 🔍 Key Insights

* **YouTube** generated the highest total views at **1.29B**.
* **Instagram** achieved the highest average engagement rate at **15.04%**.
* **Video** was the most common content type with **3,007 posts**.
* **Sports, Entertainment, Technology, and Lifestyle** were among the higher-viewed topics.
* Regional engagement varied, with **Brazil** showing one of the highest average engagement rates.
